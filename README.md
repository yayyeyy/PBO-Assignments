# Yayy's Object-Oriented Programming Assignments

## Assignments

### 1. Array and ArrayList
This assignment contains Java programs related to arrays and ArrayLists.

**Concepts:**
- **Array:** Stores multiple values of the same data type in a fixed-size collection.
- **ArrayList:** Stores multiple elements and allows the collection to grow or shrink dynamically.

### 2. Inheritance and Polymorphism
This assignment contains Java programs that demonstrate inheritance and polymorphism using object-oriented programming concepts.

**Concepts:**
- **Encapsulation:** Protects data within a class using access modifiers, such as `private`, and provides controlled access through methods.
- **Inheritance:** Allows a class to inherit attributes and methods from another class. In this assignment, `Square`, `Circle`, and `Cylinder` inherit from the `Shape` class.
- **Polymorphism:** Allows the same method to behave differently depending on the object that uses it. Different shape classes can provide their own implementations of inherited methods.
